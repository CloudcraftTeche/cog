# COG — Scripture School LMS

Documentation index for this repository. This is a full-stack Learning Management System with a Next.js client and an Express/MongoDB server, organized as a monorepo:

```
cog/
├── client/   # Next.js 15 (React 19) frontend
├── server/   # Express 5 + MongoDB (Mongoose) backend
└── docker-compose.yml
```

## Tech Stack Summary

**Frontend** (`client/`): Next.js 15 (App Router, Turbopack), React 19, TypeScript, Tailwind CSS v4, Radix UI + shadcn-style components, TanStack React Query v5, Axios, Socket.IO client, React Hook Form + Zod, Sonner, Recharts, XLSX. See [client/package.json](../client/package.json).

**Backend** (`server/`): Node.js, Express 5, TypeScript, Mongoose (MongoDB), JWT + bcrypt auth, Socket.IO, Multer + Cloudinary, Nodemailer, Helmet, CORS, express-rate-limit, express-validator. See [server/package.json](../server/package.json).
